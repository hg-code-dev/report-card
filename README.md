# Simple Student Report Card

A beginner Python project built during the freeCodeCamp workshops to practice variables, data types, and output formatting.

## Features
- Stores student information (name, age, status, and score).
- Uses built-in functions like `type()` and `isinstance()` to check data types.
- Displays clean, formatted outputs using Python f-strings.

## How to Run
1. Make sure you have Python installed on your computer.
2. Clone or download this repository.
3. Open your terminal or VS Code and run the script:
   ```bash
   python report-card.py
